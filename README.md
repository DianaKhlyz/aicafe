# Сайт кафе с интеграцией iiko

Сайт кафе смешанного типа: доставка, самовывоз ко времени, бронь столов,
QR-меню за столом с онлайн-оплатой — всё поверх iiko как единого источника
правды.

**Статус проекта: каркас.** Архитектура согласована и зафиксирована в
`docs/`, собран рабочий скелет: бэкенд на мок-данных iiko (реальный
apiLogin появится ~через месяц), фронтенд с меню, корзиной и режимом
«за столом». Каждый следующий блок обсуждается перед реализацией.

## Запуск

```bash
make install        # зависимости бэка (uv) и фронта (npm)
make dev-backend    # FastAPI на :8000 — мок-режим iiko
make dev-frontend   # Vite на :5173 — проксирует /api на бэк
make test           # тесты бэка
make lint           # ruff + tsc
make types          # перегенерация TS-типов из OpenAPI-схемы
```

## Ключевые решения одной строкой

- **iiko — единственный источник правды** по меню, ценам, стоп-листам, заказам, столам и резервам. Сайт читает, кэширует и отправляет — ничего не дублирует.
- **Стек:** FastAPI (BFF) + Vite SPA с пререндером публичных страниц + SQLite (WAL) + Caddy + systemd на VPS в РФ. Без Postgres, Redis, очередей и Kubernetes.
- **QR-меню — это не отдельный продукт, а режим сайта** (`/t/{стол}`): одно меню, одна корзина, один код — три канала продаж.
- **Mobile-first** — жёсткое требование к дизайну и вёрстке.
- **Тариф iiko: Pro** (включает API, iikoCard, резервы столов, QR-меню, iikoWaiter). Доступ к API появится ~через месяц от 2026-07-08.
