# Концепция

## Цель

Собственный сайт кафе с прямой интеграцией в iiko вместо готовых конструкторов
(Restik, GetMeBack, PremiumBonus и т.п.), которые берут абонентку 5–20 тыс ₽/мес
и/или процент с оборота. Всё, что они продают как сервис, строится на публичном
iikoCloud API — платим один раз разработкой и владеем каналом продаж сами.

Три принципа основы:

1. **Быстро и ненагруженно.** Меню отдаётся из кэша/статики, iiko дёргаем
   минимально. Сайт живёт, даже если iiko временно недоступен.
2. **Гибко.** Каждая фича за фичефлагом; интеграции (iiko, оплата) за
   интерфейсами — mock-реализация для разработки, боевая подключается без
   переписывания кода.
3. **Качественно.** Типизация везде, валидация входных данных, дизайн-токены
   вместо хардкода стилей — итоговый макет дизайнера ложится заменой токенов.

## Фичи для гостей

### Базовые (MVP)

- Меню с категориями, поиском, тегами (острое / веган / новинка), модификаторами
  (молоко, сироп, размер) — данные из номенклатуры iiko.
- Корзина и оформление: доставка / самовывоз, адрес с подсказками, время
  «как можно скорее» или ко времени, промокод.
- Онлайн-оплата (СБП + карта, эквайринг банка владельца через адаптер
  `PaymentProvider`) или оплата при получении. Заказ падает прямо на кассу
  iiko — персонал ничего не перебивает руками.
- **Статусы заказа в реальном времени** (вебхуки iiko): принят → готовится →
  «готов, можно забирать» / «передан в доставку». Физическую доставку выполняет
  агрегатор, поэтому карту курьера не делаем — трекер работает на самовывоз
  и этапы кухни.
- Личный кабинет: история заказов, повтор заказа в 1 клик, сохранённые адреса.
- Вход по номеру телефона (код через Telegram Gateway / flash call — в разы
  дешевле SMS).

### Лояльность (фаза 2)

- Бонусная программа через iikoCard: начисление/списание на сайте и на кассе —
  один баланс везде.
- **Карта лояльности в Apple/Google Wallet** с живым балансом (обновление пушем
  по вебхуку). Готовые сервисы берут за это отдельную абонентку — у нас это
  PassKit + свой бэкенд.
- **Промо-движок** — единая структура для промокодов, купонов, акций, комбо
  и подписок с расчётом через iiko loyalty/calculate: цена на кассе и на сайте
  всегда совпадает. Подписки/абонементы (N чашек в месяц) — та же структура,
  включаются по бизнес-решению.

### «Вау-фичи» (то, чего нет у конкурентов или стоит дорого)

- **Предзаказ ко времени с умными слотами**: гость выбирает время, сайт
  предлагает ближайшие доступные слоты с учётом загрузки кухни. Модель простая
  на старте (мощность кухни на 15-минутный слот минус уже принятые заказы),
  а реальные тайминги готовки для её уточнения бесплатно даёт сам iiko —
  интервалы CookingStarted → CookingCompleted из вебхуков. В iiko заказ уходит
  сразу как отложенный (`completeBefore`).
- **QR-заказ за столом**: скан QR на столе → меню → заказ → оплата СБП, без
  официанта. Аналоги стоят процент с оборота.
- **Отзывы только от реальных заказов**: после закрытия заказа (вебхук) гостю
  уходит ссылка на оценку. Оценка ≤ 3 — мгновенный алерт менеджеру в Telegram,
  пока гость не написал на Яндекс.Картах.
- **Персонализация**: «ваш обычный заказ», «с этим берут», рекомендации из
  истории заказов гостя.
- **Telegram-бот как второй фронт**: статусы, повтор заказа, баланс бонусов —
  тот же бэкенд, минимум кода.
- Бронирование стола с виджетом свободных столов (резервы iiko), депозит онлайн.

## Фичи для персонала и бизнеса

- **Автоматический стоп-лист**: блюдо закончилось на кухне → вебхук → блюдо
  скрыто на сайте за секунды. Никаких звонков «а этого нет».
- **Алерты в Telegram**: заказ висит неподтверждённым > 5 минут, отмена заказа,
  ошибка доставки заказа в кассу, плохой отзыв, вырос стоп-лист.
- **Контент-админка**: баннеры, акции, тексты, порядок категорий, свои фото блюд
  (поверх iiko-шных), фичефлаги.
- **Дашборд владельца**: выручка по каналам, средний чек, топ блюд, скорость
  кухни — из накопленного у себя зеркала заказов (без лишних запросов в iiko).
- **RFM-сегментация**: «уснувшие» гости получают купон на возврат — то, за что
  платят PremiumBonus.

## Дополнительные идеи (к обсуждению)

- **Повышенный кэшбэк за самовывоз и заказ через сайт** — экономика: агрегатор
  забирает 15–35% комиссии, бонусами вернуть гостю 5–10% на своём канале всё
  равно выгоднее. Главная фича для миграции гостей из агрегаторов.
- **Бронь + предзаказ блюд к брони** — та же механика слотов, что и предзаказ
  ко времени: пришёл — стол накрыт.
- **Групповой заказ по ссылке** — один открывает корзину, коллеги накидывают
  блюда со своих телефонов, платит один. Дёшево в разработке, любят офисы.
- **Электронные подарочные сертификаты** — продажа на сайте, номинал ложится
  в кошелёк iikoCard; выручка авансом.
- **Безналичные чаевые по QR** — сервисы типа Netmonet берут комиссию/абонентку;
  можно отдать готовым сервисом на старте и заменить своим QR со СБП позже.
- **PWA + web-push** — сайт устанавливается на домашний экран как приложение,
  пуши о статусе заказа и акциях бесплатны; полноценное мобильное приложение
  можно отложить без потери функций.
- **SEO-разметка Schema.org (Menu, LocalBusiness) + Яндекс Бизнес** — меню
  подтягивается в поиск и карты, бесплатный трафик.
- **Дашборд каналов для владельца** — маржа сайт vs агрегатор в одном экране:
  видно, сколько реально стоит каждый канал и как работает кэшбэк-миграция.

## Почему это дешевле готовых решений

| Готовое решение | Абонентка | Наш аналог |
|---|---|---|
| Конструктор сайта с iiko (Restik и т.п.) | от ~4–10 тыс ₽/мес | свой сайт, разовая разработка |
| Программа лояльности (GetMeBack, PremiumBonus) | от ~5–15 тыс ₽/мес | iikoCard API + Wallet-карты |
| QR-оплата за столом | % с оборота или абонентка | свой QR-флоу + СБП (комиссия 0.4–0.7%) |
| Электронное меню | от ~1–3 тыс ₽/мес | страница /menu того же сайта |

Постоянные расходы остаются только за: лицензию iiko с API-модулем, эквайринг
(комиссия), хостинг (VPS ~500–1500 ₽/мес), домен.
