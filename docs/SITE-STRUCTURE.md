# Структура сайта

## Карта сайта

```
/                       Главная
/menu                   Меню (категории, поиск, теги)
/cart                   Корзина
/checkout               Оформление заказа
/order/[id]             Трекер заказа (публичная ссылка)
/promo                  Акции и новости
/booking                Бронирование стола
/about                  О нас, контакты, карта, зона доставки
/account                Личный кабинет
  /account/orders         История заказов + повтор
  /account/addresses      Сохранённые адреса
  /account/loyalty        Бонусы, карта лояльности, Wallet
/legal/offer            Публичная оферта
/legal/privacy          Политика обработки ПД (152-ФЗ)
/admin                  Служебная админка (контент, фичефлаги, зеркало заказов)
/t/[table]              QR-заказ за столом (фаза 3)
```

## Страницы

### Главная `/`

Hero с УТП и кнопкой «Заказать», лента акций, популярные блюда (добавление в
корзину прямо с главной), блок доставки (зона, время, минимальный заказ),
отзывы, контакты. Всё — редактируемые блоки из админки.

### Меню `/menu`

Якорная навигация по категориям (sticky-панель), карточки блюд: фото, цена,
вес/калории, теги. Клик — модалка/страница блюда с модификаторами и составом.
Блюда из стоп-листа скрываются автоматически. Данные приходят из кэша BFF —
страница рендерится сервером и открывается мгновенно.

### Корзина `/cart` и чекаут `/checkout`

Корзина живёт в localStorage (гостю не нужен аккаунт до оформления).
Чекаут: контакты → способ получения (доставка/самовывоз) → адрес (подсказки) →
время → оплата (онлайн / при получении) → промокод/бонусы. Валидация на клиенте
и на сервере (zod). После оплаты — редирект на трекер.

### Трекер `/order/[id]`

Лента статусов (принят → готовится → в пути → доставлен) с автообновлением.
Доступен по ссылке без входа (id — неугадываемый uuid). Сюда же ведёт ссылка из
SMS/Telegram-уведомления. После статуса «доставлен» — форма оценки заказа.

### Бронирование `/booking`

Форма: дата, время, число гостей, пожелания. Фаза 2: виджет свободных столов из
резервов iiko, депозит онлайн.

### Личный кабинет `/account`

Вход по телефону + код. Профиль, история заказов с повтором в 1 клик, адреса,
бонусный баланс и кнопка «Добавить карту в Wallet».

### Админка `/admin`

Не дублируем iiko (заказы, меню и цены ведутся там) — только то, чего в iiko
нет: баннеры и тексты, порядок/скрытие категорий, свои фото блюд, акции на
сайте, фичефлаги, статус синка меню, зеркало заказов (read-only) и журнал
ошибок интеграции.

## Состояния и сквозные элементы

- **Шапка**: логотип, навигация (Меню, Акции, Бронь, О нас), телефон, кнопка
  корзины со счётчиком и суммой. На мобильном — нижняя таб-панель
  (Меню / Акции / Корзина / Профиль).
- **Гость vs авторизованный**: весь путь до оплаты доступен без входа; телефон,
  введённый в чекауте, мягко предлагает создать аккаунт (код подтверждения).
- **Заведение закрыто**: баннер «откроемся в 9:00», доступен предзаказ ко
  времени открытия.
- **iiko недоступен**: меню продолжает отдаваться из кэша; оформление заказа
  показывает «примем заказ по телефону» + заказ ставится в очередь на повторную
  отправку (фаза 2).
- **Блюдо в стоп-листе**: исчезает из меню; если уже в корзине — помечается
  «закончилось» на чекауте.
